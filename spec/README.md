# Specifications

Contracts that more than one package implements. A specification is normative:
when an implementation disagrees with it, the implementation is wrong, or the
specification changes first in its own pull request.

| Specification                | What it defines                                                                     | Implemented by                                         |
| ---------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------ |
| [qualify](qualify/README.md) | Qualification test declaration, checks, evidence files, redaction and the trace CLI | TypeScript, Python, Java and C# packages (in progress) |
